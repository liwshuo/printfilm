分集大纲 · 每集一个成语

系列设定完成后，为每集生成剧本骨架。每集独立故事，围绕一个成语 / 寓言核心价值。

✨ 从 idea 一键生成分集大纲
给一个方向或一批成语，AI 会一次性生成本辑所有集的标题 / 摘要 / 核心寓意 / 主要角色。你只需在下方卡片流里微调 / 换风格 / 补齐。
不写 idea 也能点，会用系列设定 + 内容形态默认预设兜底 生成后每张卡片都可以「🔄 重生成 / 🎲 换风格 / 🩹 补齐字段」

P0-1阶段进度栏
左侧 260px 固定，6 步线性阶段（项目设定 → 导出）。每步一个状态灯：✓ 完成 / 数字 · 进行中 / 灰 · 未解锁。 阶段之间阻塞（前置未完不能跳），阶段内自由。参考 huobao-drama + CineGen Phase 01-04。
P0-2AI Pre-fill 面板
主内容区顶部大面板，一句 idea + 少量下拉，一键生成全部分集草案。参考 huobao 一键改写 + drama-skills 主动填充。 每张卡片都可 🔄 重生成 / 🎲 换风格 / 🩹 补齐，不需要用户懂 prompt。
P0-3分集卡片流
每集一张卡：集号 + 标题 + 摘要 + 5 灯状态条（剧本 / 场次 / 关键帧 / 视频 / 导出）+ 动态 CTA（按当前状态切）。 参考 huobao 剧集列表 + CineGen 网格分镜表。副菜单 ⋯ = 重生成 / 换风格 / 删除。
交互动态 CTA
每张卡的主按钮文案随当前状态变化：
剧本 ✓ 场次 ○ → 进入场次 →
场次 ✓ 关键帧 ○ → 进入关键帧 →
关键帧 ✓ 视频 ○ → 生成本集视频 →
全绿 → 查看本集时间轴
交互顶部项目切换
顶栏项目选择器 + 内容形态徽章。切项目后左侧阶段进度自动同步该项目的状态。 右上有 ⚙️ 项目设置（含变更内容形态、导入原文、删除项目等）。
